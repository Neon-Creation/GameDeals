# GameDeals

Projeto de estudo para aprender e praticar UIKit desenvolvendo um aplicativo de ofertas de jogos.

## Objetivos

- Aprender a criar interfaces e navegação com UIKit.
- Consultar promoções de jogos da Steam usando a API CheapShark.
- Apresentar informações de ofertas, como jogos e preços.
- Evoluir o aplicativo conforme o aprendizado do projeto.
